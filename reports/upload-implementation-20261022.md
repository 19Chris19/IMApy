## 可靠性覆盖

逐项明确拒绝会记录后继续，未知写入、认证、权限或配额问题暂停整批。HTTP 200 不代替新增材料身份；改名不代替无覆盖证明。恢复前重新核对已分配对象，迟到完成不能导致覆盖或重复登记。原请求键绑定目标、文件顺序、摘要和文件身份。

测试还覆盖：空文件、格式伪装、损坏/加密标记、全部后缀的负例路由、动态大小策略、100 文件分页、文件变化、取消、断网/超时、磁盘保存拒绝、回执丢失、部分日志尾部、跨 profile/目标身份、私有权限、同 profile 的问答/续期互斥。格式负例和有界头部检查不是完整文档有效性验证，也不是合法样本上传通过。

## 资源测量

同一离线进程，两个独立合成 profile。先 30 轮问答基线，再 30 轮问答与小文件上传并行；随后 4、16、64 MiB 文件各一轮，再重复两轮 64 MiB。没有真实网络/COS、模型或 GPU 任务。

| 指标 | 实测 |
| --- | --- |
| 读取/传输块上限 | 64 KiB |
| 连续小批次第 5 → 30 批，对象堆 | 9.79 → 10.04 MiB |
| 同期整个测试进程 RSS | 78.66 → 87.09 MiB |
| 三轮 64 MiB 后 RSS | 121.91 / 123.33 / 123.67 MiB |
| 三轮 64 MiB 后对象堆 | 10.04 / 8.77 / 8.78 MiB |
| 整个进程 RSS 峰值 | 123.67 MiB（含 Node、模拟器和问答，非上传额外占用） |
| 合成问答首段 P95，基线 → 并行 | 56.37 → 96.07 ms |
| 每轮事件间隔 P95 的跨轮 P95，基线 → 并行 | 22.05 → 31.55 ms |
| 整轮事件循环延迟 P95 / 最大 | 11.40 / 29.75 ms |
| 测量中上传日志总量 | 141848 字节 |

本窗口中对象堆没有随文件大小线性增长，重复大文件的 RSS 趋于平台；这不能证明长期绝无增长。缓冲分配仍使 RSS 上升，并发合成问答首段额外约 39.69 ms，事件间隔指标额外约 9.50 ms，不能宣称零开销。该指标是“每轮事件间隔 P95 再取跨轮 P95”，不是所有事件合并计算的 P95。OS 文件计数返回零时不据此声称没有磁盘写入或 SSD 写入。
