# 文件入库候选：先规划，再按授权发送

当前内置真实上传适配器关闭，返回 `upload_web_contract_unverified` 时直接说明缺口并停止。真实网页入口已观察到客户端要求；后续文件入库选择官方 OpenAPI，独立于扫码问答身份。不要把配置凭据当作适配器已实现，也不要借用 Provider、其他账号或桌面客户端绕过关闭状态。22 个后缀是静态研究范围，官方 API 的格式、权限及逐格式真实支持须另行验收。既有问答能力不受影响。

## 官方上传凭据：先给选择，再私密配置

首次涉及真实上传时，向用户说明：需要本人在 [IMA 官方开放平台](https://ima.qq.com/agent-interface)申请的 **Client ID** 和 **API Key**；这是两项字符串凭据，不是扫码结果或验证码。IMApy 提供接入工具，不签发官方凭据，不提供默认共享 Key，也不能靠我们的账号取得用户个人库的写权限。

通过 Agent 可用的交互选择框提供以下选项；没有选择框时用普通文字列出同样的选择，但不在聊天中收集凭据：

1. **配置我自己的官方凭据**：引导用户在官方页面申请，然后打开本机私密配置表单。表单分别标明 Client ID、API Key；API Key 遮掩显示，内容只由本机配置程序接收和私有保存，不回传给 Agent 或写入聊天、命令参数、日志及 Git。保存后只向 Agent 返回是否已配置及配置标识。
2. **使用已配置的官方凭据**：只检查配置存在性和绑定身份，不展示凭据，不混用其他 profile。已配置不代表有目标库写权限；首次线上权限核对仍需属于用户当前授权范围。
3. **暂不配置，只规划文件**：只做本地文件检查，不访问 IMA，不上传。用户取消时结束上传流程。

宿主只有普通文本提问框、无法保证密钥不进入对话或模型时，不能假装它是私密表单；改为引导用户在本机私密配置入口自行填写，Agent 仅接收完成状态。**当前候选尚未实现该表单、官方凭据保存及 OpenAPI 上传适配器**：明确报告待开发，只提供官方申请地址和本地规划，不编造配置命令，不索要密钥，不因用户已申请凭据而尝试发送。

配置凭据与同意上传分开：发送前仍要确定文件清单、目的地和本次授权。Client ID/API Key 仅用于官方 IMA API；文件传输使用官方返回的临时 COS 凭据，不能向存储服务器转发 IMA Key、扫码 Cookie 或问答凭证。权限核对失败时停止，不切换到维护者共享凭据。

## 明确文件和目的地

取得用户明确的文件清单及知识库/文件夹 ID。没有精确 ID 时只能沿用户授权读取知识库目录；不能按库名相似、列表位置或默认 3DGS 共享库代选。首次真实验收限定独立测试账号已有个人库。

调用 `ima_upload_plan` / `ima-local upload plan --input PRIVATE_JSON --json` 只做本地检查与摘要，不访问 IMA。不要递归扫描目录、附带其他文件，单批最多 100 个。向用户说明明确文件、目的地、稳定改名另存、不覆盖，以及不会自动提问。已有明确上传指示时不反复请求相同授权；未授权发送则只完成规划。

不要把规划结果直接作为提交 JSON：提交只接受 `requestKey`、`knowledgeBaseId`、可选 `folderId`、按顺序的绝对文件路径 `files`。请求 JSON 保存私有目录，权限 0600。先持久保存原始请求键和清单，再发送；不得把凭据、签名、Cookie 或上传 URL 放进参数。

## 进度与恢复

`ima_upload_batch` 返回本地批次 ID，不表示已入库。调用 `ima_upload_status`，运行中至少间隔一秒，按 `offset` / `limit` 分页。对外说明当前真实阶段：传输完成、已登记、解析中、解析完成；解析完成不能代替可检索/引用验收。

宿主重启默认只读进度。需要新线上读取时，按授权使用 `ima_upload_reconcile`，它只核对已有对象，不上传；进一步发送必须明确 `ima_upload_resume`。同键不同清单、顺序、摘要或目的地会拒绝，不能换新键规避。

- 单项明确失败：保留结果，其他项按原批次继续；失败项不会自动重传。
- `needs_reconciliation` / `outcomeUnknown`：整批停止。不能凭 HTTP 200 或材料标题猜成功，不能自动重问、清保护或换键重传。
- 认证、权限、配额变化：先报告暂停原因，不自动扫码、续期、换库或换号。
- `storage_recovery_required`：保留日志原件，不能截断、覆盖或删除来恢复发送。
- `ima_upload_cancel` 只停止本进程和本地队列，不证明上游停止，也不删除材料。不要向用户声称回滚成功。

## 完成后的核验

交付批次 ID、每项阶段/材料 ID 与脱敏失败说明。不得输出临时签名或上传凭据。提问取材是独立操作：用户另行授权后才调用原问答工具，明确检查检索及引用证据。测试材料默认保留，交由用户整理；本候选不提供自动删除、覆盖、建库或批量目录导入。
