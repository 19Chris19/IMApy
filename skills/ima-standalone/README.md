# 独立 IMA 取材 Skill

为 Agent 固定个人登录、准确选库、模型/模式选择、稳定请求键、任务恢复
和证据核验流程，减少现场摸索网页协议及错误重试。

随独立 ima-local 安装包提供，不需要 Provider 服务或账号池。
用 `ima-local skill path --json` 查看路径；安装到宿主前取得用户授权。
没有 MCP 时可走同一套 CLI 流程，不要求修改宿主配置。

需要 Node.js 22。macOS Apple Silicon 已有分项限次的登录、续期、四模型
快速/深度与追问记录；固定 S4.16 包还通过 GLM 快速联网首问、新 CLI 同会话
追问及两次离线恢复/导出核对。范围不外推到跨天、原生 Agent 或其他系统。
新版只读 `readiness` 区分可尝试、需续期、需登录与结果未定；其本身不调用上游。
联网需要网络和个人 IMA 权限；离线只能做本地检查、读取已保存任务与导出。
无需子 Agent。扫码需要已有 Chromium 系浏览器和桌面；日常请求不常驻浏览器。

## 边界与数据

凭证由运行时直接加密保存和使用，不需要复制到 Skill 或聊天。
本地密钥与密文同目录，不是系统钥匙串；同一用户下其他进程仍可能读取。
输出为回答、准确引用映射和明确的证据局限；不保证上游一定联网。
新版 JSON 结果保留知识库引用到明确材料 ID 的关系，并标注未读取原文。
材料正文读取、生成产物和任意资料增删改不在此版本范围。
