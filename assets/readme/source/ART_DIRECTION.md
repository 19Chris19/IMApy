# IMApy README visual source

Audience: developers and personal IMA users who want a repeatable programmatic workflow.
One-sentence value: log in once by human QR confirmation, then use IMA web capabilities from code.
Primary proof: eight bounded capability groups, recorded acceptance scope, and reproducible offline checks.
First successful action: download the alpha package, verify it, install and run a local-only doctor check.
Visual theme: an open knowledge folio becoming a structured interface.

Palette: warm paper #F6F8F5 / ink #142D2A / mint #087B62 / blue #286CE2 / muted #61736D.
Typography: system sans-serif; large editorial title; monospace only for interface names.
Shape: 24-unit corners, 2-unit strokes, generous 40-unit spacing.
Motif: indexed paper leaves and explicit connections, reflecting knowledge, citations and sessions.
Composition: quiet editorial; the generated material is a conceptual illustration, never a live screenshot.

The ImageGen subject is the material layer only. Exact words and geometry are SVG.
The animated diagram explains login -> independent SDK -> interfaces; it is not a recording or speed claim.
README text, commands, capability table, limits and contribution links remain searchable Markdown.
Animation has a static fallback and a deliberately still reading interval.

No third-party preview service, remote font or tracking image is used. These repository assets do
not add any code or network request to the IMApy runtime or to the running Provider services.
