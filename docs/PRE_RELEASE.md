# IMApy v0.1.0-alpha.2 — 独立 IMA 网页能力开发预览

这是 IMApy 的开发预览版，供独立安装和评审；不是稳定生产版。
人工扫码后，使用 SDK、CLI、STDIO MCP 与 Skill 调用有明确证据的 IMA 网页能力。

包含模型与快速/深度选择、指定知识库问答、联网意图与实际证据区分、精确引用、
同会话追问、任务恢复、导出及显式凭证维护。无需 Provider A 或常驻浏览器。

**本版仅提供能力表中的 8 类已打通核心能力，支持范围以对应验收记录为准。**
材料目录/全文、报告/PPT/播客、长期记忆、资料增删改等仍在开发或调研，
不属于当前功能承诺。跨天维护、真实 Agent/Skill 闭环及生产迁移仍待验收。
后续按普通网页可行性和验收结果逐项开放，不预告未证实能力的交付时间。

包名和命令仍为 `@ima-local/standalone` / `ima-local`。安装使用附带 `.tgz`；
没有公开 npm 发布。先核对 `SHA256SUMS`，再参照 README 和使用指南。

历史真实记录的版本、账号范围和入口见能力表。当前候选只增加本地离线验收，
不把旧成功记录当作全部功能的当前真实证明。Provider 为实验适配；跨天维护、
其他平台、真实 Agent 取材、原文读取及生产迁移尚未全部验收。

安装包、干净源码和校验文件见本次 GitHub Pre-release 附件；按 README 安装。
源码只包含清理后的发布文件，不包含原研发 Git 历史、个人登录态或真实问答。

本版包含 Windows 兼容修复与文件上传候选。Windows 已通过原生合成测试，真实扫码尚待验收；文件上传规划和恢复仅供开发测试，实际上传适配器、官方凭据私密配置和格式验证均尚未完成。
