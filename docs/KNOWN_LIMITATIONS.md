# 已知限制与失败处理

本版仅提供 README 和能力表列出的 8 类已打通核心能力。其余项目即使已有代码、
工具入口或路线图记录，也仍属开发、调研、实验或待验收范围；后续逐项确认后再开放。

- IMApy 是非官方的 IMA 普通网页协议工具，不是腾讯官方 SDK；上游协议及权限可能变化。
- 首版为开发预览，真实记录主要来自 macOS arm64、Node 22 的旧固定版本和限定账号。
  Linux/Windows、所有模型/入口组合和当前候选真实 Agent 取材未全部验收。
- 问答可能等待较长时间；历史联网两轮首段约 20/39 秒，包含本地处理，非浏览器绘制
  或纯网络测量。没有把合成流表现当成实际上游延迟保证。
- 首次登录需要临时浏览器和人工扫码；登录后通常使用 HTTP/SSE，不能保证永不重扫。
  后台续期默认关闭，单次成功不证明跨天长期运行。
- 一份个人 profile 同时一轮；明确保护活跃操作、身份、锁和代际。不提供无限自动重试。
- `indeterminate` 或认证 `outcome_unknown` 表示不能确认上游结果；保留原任务、请求键
  和保护记录。只读查询不能证明上游未执行，也不能授权清标记。
- 网页引用只对上游明确关联的键、编号与来源建立关系，不按数组顺序猜配。
  引用准确不代表网页可信、官方优先或内容已全文核验。
- 知识库材料 ID 不等于读取权限；本版不承诺材料全文、报告、PPT、播客、长期记忆、
  资料增删改或客户端专属功能。
- 本地密文与密钥同目录，不防同一用户权限下的其他进程；不要上传 profile 或原始日志。
- Provider 适配的真实五账号迁移、Air 策略、远程二维码、未知续期保护下的正常停机交接、
  真实切换/回滚和长期运行尚未验收。合成测试专用清理不能替代生产停机证明。

故障时先运行本地 `status`、`auth status`、`auth lock-status`。到期可在授权下显式续期；
未知结果停止新请求。禁止通过换账号、换 profile、改请求键或删除锁/保护文件绕过。
