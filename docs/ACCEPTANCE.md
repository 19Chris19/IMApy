# 能力与验收范围

开发预览版：`0.1.0-alpha.2`。区分实现、合成、历史限定实测和当前候选验收。
以下历史记录不会验证当前用户的账号，也不授予新请求权限。

## 本版支持范围

仅将以下 8 类已打通并有验收依据的能力作为首版提供范围。这里的成熟度限开发
预览版和已测试路径；完整离线回归不替代当前候选的真实账号、跨平台或长期验收。

| 能力 | 已有证据 | 首版限制 |
| --- | --- | --- |
| 1. 独立扫码登录与设备上下文 | macOS arm64、旧 S4.8 限定真实流程 | 人工确认；其他平台和浏览器组合待验收 |
| 2. 无浏览器 HTTP 续期 | 旧 S4.12 单次提交、新进程读回及认证只读检查 | 显式续期；不含跨天自动维护 |
| 3. 指定知识库流式问答 | 独立 SDK/CLI/官方 SDK 驱动 STDIO 的旧版分项实测 | 准确选库；非所有账号或入口组合 |
| 4. 快速／深度模式 | 四模型的旧版分项真实记录 | 非所有切换排列 |
| 5. 模型切换 | DeepSeek、Hy3、Hy4、GLM 的同会话真实记录 | 模型以实际目录和账号资格为准 |
| 6. 连续追问与重启延续 | 旧版 SDK/CLI/MCP 分项及新进程追问实测 | 非任意跨天上下文保证 |
| 7. 联网与精确网页引用 | S4.16、GLM 快速、单账号单库两轮完整流及逐键核对 | 不保证每次联网，不等于原文核验 |
| 8. 任务恢复与结果导出 | 已完成结果的离线读回、重启及导出一致 | 未知结果保留；异常路径另有合成测试 |

独立安装、本地检查和 SDK/CLI/MCP 是上述能力的使用入口。Skill 是取材和证据
核验指引。安装、发现和模拟流程通过，不等于当前候选真实 Agent 取材已经通过。

## 不属于本版承诺

| 状态 | 能力或验收项 | 后续安排 |
| --- | --- | --- |
| 已有部分实现，继续开发 | 材料目录、知识库引用到材料、按需材料原文 | 身份不等于全文权限；先完成网页路径与真实读取验收 |
| 调研中，尚未打通 | 报告、PPT、播客、长期记忆、资料增删改 | 仅研究普通网页能力，不承诺客户端专属路径或交期 |
| 已有实现，待真实验收 | 当前候选 Agent/Skill 完整取材、跨天自动维护、其他平台 | 按各自范围单独验收后再提升支持等级 |
| 实验性下游适配 | Provider 账号池迁移、管理与生产切换、Air、远程二维码 | 不作为个人首版生产服务交付 |

只有完成对应路径的验收后，才在后续版本中纳入正式提供范围。代码、工具或路线图
出现某项能力，不表示已经向用户承诺可用；上述项目按可行性和证据陆续推进。

公开证据位于 `reports/public/`：均为固定字段白名单投影，包含原报告 SHA-256；
原报告、私有抓包、真实历史和旧失败现场留在原研发环境，不随源码或安装包分发。
投影不含问题、答案、账号/任务 ID、资料标题/URL、个人路径或注册命令。

历史原生报告保留当时的“当前聊天未验证”字段。2026-10-21 在本聊天只核验了
工具与 Skill 可见性，无 IMA 请求；另存 `reports/public/chat-visibility.json`，
不把它冒充安装新候选、真实问答或 Skill 核验闭环。

最终离线测试、安装与文件审计结果随 GitHub 预发布单独附带。
远端构建与测试见 [GitHub Actions](https://github.com/19Chris19/IMApy/actions)。
本版是开发预发布，没有 npm 发布，也不涉及现有生产服务部署。
