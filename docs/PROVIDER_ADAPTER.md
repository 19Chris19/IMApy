# 实验性 Provider 适配

`@ima-local/standalone/provider-adapter` 是受信宿主接口，不是完整 Provider 服务。
个人安装和使用不需要 Provider URL、服务凭据、Docker 或账号池。

宿主负责应用权限、真实账号租约、CAS/可靠提交、维护互斥、排空、持久任务和网络授权。
适配器不能代替这些责任；不应把临时内存回调直接作为生产持久化实现。

接口覆盖协议、错误边界、任务/会话编排、提交恢复、上游派发意图、登录上下文与资格
检查等本地能力。源码测试用模拟上游；实际 Provider 管理页、恢复、迁移与旧机器人
兼容补丁保留在原项目研发线，不嵌入个人安装包，也不承诺可直接替换生产实现。

当前导出路径保持兼容，首版明确实验性质。对接前分别评审错误、身份、未知结果、
存储、关闭和迁移约束；真实账号接入与上线应另行验收及备份，不覆盖现有运行目录。
